## Affected

- **Endpoint:** `POST /api/vehicles/import`
- **Componente:** [`XmlParserService.parse()`](../../app/src/main/java/co/fleetsec/vapp/service/XmlParserService.java#L30) — `DocumentBuilderFactory` sin hardening.

## Description

`XmlParserService.parse()` usa `DocumentBuilderFactory.newInstance()` con la configuración por defecto, que **no** deshabilita DTDs ni entidades externas:

```java
DocumentBuilderFactory dbf = DocumentBuilderFactory.newInstance();
// NO se setea disallow-doctype-decl ni FEATURE_SECURE_PROCESSING
Document doc = builder.parse(new InputSource(new StringReader(xml)));
return doc.getDocumentElement().getTextContent();  // entidad externa ya expandida
```

Un documento con una entidad externa `SYSTEM "file:///..."` se expande al parsear y su contenido se refleja en la respuesta.

## CVSSv3.1 — justificación métrica por métrica

`CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N` → **7.5 (High)**

|---|---|---|
| **AV/AC/PR/UI** | N/L/N/N | Endpoint HTTP, payload XML directo, sin auth (V-11). |

## PoC

```bash
curl -s -X POST http://localhost:8080/api/vehicles/import -H "Content-Type: application/xml" \
  --data-binary '<?xml version="1.0"?><!DOCTYPE r [<!ENTITY xxe SYSTEM "file:///etc/hostname">]><r>&xxe;</r>'
# → {"parsed":"c9cdf39b5a43\n"}   ← contenido de /etc/hostname leído vía XXE
```
Con `file:///etc/passwd` se obtiene el mapa de usuarios; con `http://` la entidad externa deriva en SSRF (ver V-03).

### Por qué el scanner NO lo caza (bien)

- **DAST (ZAP):** la regla XXE quedó PASS — el endpoint espera `application/xml` con un payload de entidad específico que ZAP no craftea desde el OpenAPI (schema `string`). **SAST:** los rulesets no marcaron esta factory específica.
- → Detectable por análisis manual + PoC dirigido.

## Impact

- **Confidencialidad (Alta):** lectura de archivos locales (config, secrets, `/etc/passwd`). Vía entidades `http://`, SSRF interno (encadena con V-03).
- **Ley 1581:** si se leen archivos con PII o config con credenciales, exposición de datos personales.

## Remediation

Deshabilitar DTDs y entidades externas en la factory:

```java
DocumentBuilderFactory dbf = DocumentBuilderFactory.newInstance();
dbf.setFeature("http://apache.org/xml/features/disallow-doctype-decl", true);
dbf.setFeature("http://xml.org/sax/features/external-general-entities", false);
dbf.setFeature("http://xml.org/sax/features/external-parameter-entities", false);
dbf.setXIncludeAware(false);
dbf.setExpandEntityReferences(false);
```

**Test dual (implementado · commit `c1ad831`):**
1. **Rechazo:** `InputValidationRemediationTest.v04_xxePayload_isRejected` — XML con `<!DOCTYPE ... SYSTEM ...>` → `400` (`disallow-doctype-decl` rechaza el DOCTYPE).
2. **Flujo legítimo OK:** `v04_cleanXml_isParsed` — un XML de import válido (sin DTD) → `200` parseado.
